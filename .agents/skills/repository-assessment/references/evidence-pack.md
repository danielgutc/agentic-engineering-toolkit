# Evidence Pack

Return only information another agent needs to continue:

## Scope

- Task or question investigated
- Applicable instructions

## Relevant structure

- Repository-level entry points, orchestration, and cross-workspace tests
- Relevant implementation workspaces, their owning boundaries, and their projects, packages, or customization assets
- Workspace-scoped toolchain files, generated output, and developer validation commands
- Architecture or requirements artifacts

## Lifecycle and abstraction

- Current product, requirements, design, architecture, implementation, and verification state
- Explicit approvals and pending gates
- Relevant requirement, decision, C4, implementation, and test identifiers

## Execution path

- Ordered flow through relevant files and symbols
- Working-directory or discovery assumptions used by build, test, package, and CI commands

## Evidence

- Facts with file references
- Inferences clearly marked as inferences

## Risks and unknowns

- Behavioral, technical, operational, and testing risks
- Questions that materially affect the next decision
